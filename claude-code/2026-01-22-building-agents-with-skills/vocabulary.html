Building agents with Skills: Equipping agents for specialized work

建议背诵 28 项

先记常见义和搭配，再用例句复习。

adoption

名词 采用；采纳

原文用法
  • rapid adoption

例句 The adoption of online invoices reduced paperwork.

采用电子账单后，文书工作减少了。

launch

动词 推出；启动

原文用法
  • we launched the Claude Agent SDK

例句 The company will launch a new rewards program in July.

公司将在七月推出新的奖励计划。

out of the box

固定短语 开箱即用；无需额外配置

原文用法
  • a production-ready agent out of the box

例句 The scanner works out of the box with most office computers.

这台扫描仪可直接在大多数办公电脑上使用。

deploy

动词 部署；调配；投入使用

原文用法
  • built and deployed these agents

例句 The retailer deployed a new checkout system in five stores.

零售商在五家门店部署了新的结账系统。

run into

动词短语 遇到（问题）；偶然碰到

原文用法
  • running into the same gap

例句 Let me know if you run into any problems with the new booking system.

如果使用新预订系统时遇到问题，请告诉我。

capability

名词 能力；功能

原文用法
  • agents have intelligence and capabilities

例句 The updated software has new reporting capabilities.

更新后的软件增加了报表功能。

expertise

名词 专长；专业知识

原文用法
  • package domain expertise

例句 We need someone with expertise in inventory management.

我们需要一位具备库存管理专长的人。

tackle

动词 着手解决；处理（难题）

原文用法
  • effectively tackle real work

例句 The committee met to tackle delays in processing refunds.

委员会开会设法解决退款处理延误的问题。

workflow

名词 工作流程

原文用法
  • codify their workflows

例句 The new workflow reduces the time needed to approve orders.

新流程缩短了审批订单所需的时间。

extend

动词 扩展；延长

原文用法
  • extending agent capabilities

例句 The supplier agreed to extend the payment deadline by a week.

供应商同意将付款期限延长一周。

financial report

名词短语 财务报告

原文用法
  • generate a financial report

例句 The financial report will be available before the board meeting.

董事会会议前将可查阅这份财务报告。

file taxes

动词短语 申报纳税；报税

原文用法
  • filing your taxes

例句 Employees can file their taxes online before the deadline.

员工可以在截止日期前在线报税。

seasoned

形容词 经验丰富的；资深的

原文用法
  • a seasoned professional

例句 We hired a seasoned supervisor to train the new team.

我们聘请了一位经验丰富的主管来培训新团队。

bridge the gap

动词短语 弥合差距；填补缺口

原文用法
  • Skills bridge this gap

例句 The workshop helps bridge the gap between classroom training and daily work.

这场研习班帮助弥合课堂培训和日常工作之间的差距。

deliberate

形容词 有意的；经过考虑的

原文用法
  • The simplicity of skills is deliberate

例句 The change was a deliberate effort to simplify the ordering process.

这项调整是为简化下单流程而有意采取的措施。

be limited to

动词短语 仅限于

原文用法
  • skill creation isn't limited to engineers

例句 The discount is limited to orders placed before Friday.

折扣仅适用于周五前下的订单。

on demand

固定短语 按需；在需要时

原文用法
  • supporting documentation loaded only on demand

例句 Training recordings are available on demand to all staff.

全体员工可按需观看培训录像。

corresponding

形容词 相应的；对应的

原文用法
  • The corresponding documentation

例句 Enter each product code in the corresponding field.

请在对应的栏位输入各产品代码。

standardize

动词 使标准化；统一

原文用法
  • skills standardize how agents interact

例句 The company standardized its expense forms across all branches.

公司统一了所有分店的费用报销表。

internal

形容词 内部的

原文用法
  • their internal processes

例句 The document is for internal use only.

这份文件仅供内部使用。

compliance

名词 合规；遵守

原文用法
  • compliance requirements

例句 The audit checks compliance with workplace safety rules.

这项审计检查工作场所安全规则的遵守情况。

coordinate

动词 协调；统筹

原文用法
  • coordinate data retrieval

例句 Maya will coordinate the training sessions for all three offices.

玛雅将统筹三个办公室的培训安排。

comprehensive

形容词 全面的；详尽的

原文用法
  • a comprehensive report

例句 The consultant provided a comprehensive review of our hiring process.

顾问对我们的招聘流程做了全面审查。

expand

动词 扩大；拓展

原文用法
  • expanding beyond engineers

例句 The company plans to expand its delivery service next month.

公司计划下个月扩大配送服务。

relevant

形容词 相关的；切题的

原文用法
  • loads only when relevant

例句 Please attach all relevant receipts to your expense report.

请将所有相关收据附在费用报告上。

quarterly results

名词短语 季度业绩

原文用法
  • Processes quarterly results

例句 The company will announce its quarterly results on Monday.

公司将于周一公布季度业绩。

administrative burden

名词短语 行政负担；文书事务负担

原文用法
  • Cuts administrative burden

例句 A shared booking system reduced the administrative burden on the front desk.

共享预订系统减轻了前台的行政负担。

portable

形容词 可携带的；可移植的（本文义）

原文用法
  • portable across tools and platforms

例句 The training materials are portable across different learning platforms.

这些培训材料可在不同的学习平台上使用。

MCP

缩写 Model Context Protocol；让 AI 应用连接外部工具和数据的协议

原文用法
  • internal databases via MCP

例句 The agent accesses the inventory database via MCP.

智能体通过 MCP 访问库存数据库。

scaffolding

名词 支撑结构；本文指智能体的配套工具和执行环境

原文用法
  • its own tools and scaffolding

例句 The prototype uses simple scaffolding to run commands and save output.

这个原型用简单的配套环境来运行命令并保存输出。

progressive disclosure

名词短语 渐进式披露；逐层显示所需信息

原文用法
  • they use progressive disclosure

例句 With progressive disclosure, the agent reads detailed instructions only when needed.

通过渐进式披露，智能体只在需要时读取详细说明。

context window

名词短语 上下文窗口；模型一次处理的输入与生成内容的容量范围

原文用法
  • protect the context window

例句 The agent summarizes old messages to save space in its context window.

智能体总结较早的消息以节省上下文空间。

metadata

名词 元数据；描述内容的信息

原文用法
  • only the metadata

例句 The catalog stores a title and description as metadata for each skill.

目录存储每个技能的名称和描述作为元数据。
